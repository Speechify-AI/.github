# Security policy

Report security vulnerabilities in any Speechify-AI repository, SDK, or the SpeechifyAI platform (`api.speechify.ai`, `platform.speechify.ai`, `speechify.ai`) to **security@speechify.ai**.

Please do not open a public GitHub issue for a vulnerability.

Include:

- The affected repository, package version, or endpoint.
- Steps to reproduce, and the impact you observed.
- Any proof-of-concept code, requests, or logs.

We acknowledge reports and keep you updated while we investigate and fix.
Please give us a reasonable window to ship a fix before disclosing publicly.

For anything that is not a security issue:

- Developer and SDK questions: `developers@speechify.ai`
- Account, billing, and API support: `support@speechify.ai`
- Sales: `sales@speechify.ai`
- Partnerships and integrations: `partnerships@speechify.ai`
