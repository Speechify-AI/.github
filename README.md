# .github

Org-wide GitHub configuration for [SpeechifyAI](https://github.com/Speechify-AI).

- [`profile/README.md`](profile/README.md) renders on the org profile page at [github.com/Speechify-AI](https://github.com/Speechify-AI).
- [`SECURITY.md`](SECURITY.md) is the default security policy for every Speechify-AI repo that doesn't ship its own.
- [`.github/ISSUE_TEMPLATE/config.yml`](.github/ISSUE_TEMPLATE/config.yml) sets fallback contact links shown when someone tries to file an issue on a Speechify-AI repo that doesn't ship its own template.

Further community health files (`CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`) and shared workflows will live here.
