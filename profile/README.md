# SpeechifyAI

SpeechifyAI on GitHub. It hosts code from the technical blog, worked examples for the [Speechify API](https://docs.speechify.ai), and public tooling for our platforms.

The flagship model, **Simba 3.0**, is a streaming-native speech model with zero-shot voice cloning, emotional expression control, and SSML prosody across 30+ locales.
